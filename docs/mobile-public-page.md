# 公開ページのスマホ表示（Issue #6）

## 変更

- 768px以下のヘッダーはメニューボタンで開閉する。閉じた状態は60px高。
- ボタンに操作名、`aria-expanded`、`aria-controls`を設定。
  Escapeで閉じてボタンへフォーカスを戻し、リンク選択でも閉じる。
- Newsの列幅をコンテナ内に収め、長いタイトル・URL・タグ・連絡先を折り返す。
- ページ全体の`overflow-x: hidden`を除去し、はみ出しを隠さず修正。
- 小画面のHero・Aboutの重複した横余白を減らす。
- ナビゲーション、作品詳細、SNS、News、フッターの主要操作に44px以上の領域を確保。

## 確認記録（2026-10-11）

ローカルViteサーバーをChromeで表示し、320・390・768・1280px幅、900px高で確認。

| 確認項目 | 結果 |
| --- | --- |
| ドキュメントの横幅と全公開セクション・フッターの要素境界 | 各幅ではみ出しなし |
| スマホの閉じたヘッダー | 320・390・768pxで60px高（変更前320pxでは198px） |
| メニュー開閉・状態通知・リンク選択・Escape後のフォーカス | 正常 |
| 自己紹介・作品・お問い合わせ・代表作品へのアンカー移動 | 正常 |
| 7作品の詳細開閉 | 正常 |
| 外部作品リンク | HTTPS、別タブ、noopenerを確認 |
| 主要操作のタッチ領域 | 44px以上。本文中のインラインURLは対象外 |
| 長い英数字タイトル・タグ・URLの一時挿入 | 各幅で折り返し、欠け・横へのはみ出しなし |
| お問い合わせ | mailtoの宛先、コピー結果通知、手動選択を確認 |

コピーの実クリックで「メールアドレスをコピーしました。」の表示を確認。
ブラウザーがコピーを拒否する場合も案内が表示され、アドレス欄を選択できる。
クリップボードの読み取りはブラウザー権限で拒否されるため、内容の再読み取りは未確認。
メール送信や外部サイト側の動作、実機Safariは確認対象に含めない。
現在Newsは5件で、「もっと見る」は通常表示されない。
管理画面はIssue #16・#21・#22の範囲。

`npm run lint`（既存AuthContextの警告1件）、`npm run build`、
`npm run test:projects`、`git diff --check`を実行して通過。
