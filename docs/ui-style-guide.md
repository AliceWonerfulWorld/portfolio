# UIスタイルと確認記録（issue #7）

公開ページと管理画面の配色・文字・操作表記を揃える。
色と既存レイアウトの変数は `src/App.css`、共通操作のスタイルは
`src/ui.css` に定義する。`ui.css` は `main.jsx` で各コンポーネントの
CSSより後に読み込み、共通ルールを適用する。

## 操作の役割

| 用途 | クラス | 表示 |
| --- | --- | --- |
| 新規追加・保存・作品を開く | `ui-button ui-primary` | 青地に白文字 |
| 編集・キャンセル・エクスポート・補助リンク | `ui-button ui-secondary` | 白地に青文字と枠線 |
| 削除 | `ui-button ui-danger` | 赤地に白文字。削除の文言も必ず残す |
| 暗い背景での主要操作 | 上記の primary に `ui-on-dark` を追加 | 白地に濃い青文字 |
| 暗い背景での補助操作 | 上記の secondary に `ui-on-dark` を追加 | 透明背景に白文字と枠線 |

hoverは背景色を変更し、focus-visibleは白と濃い青のリングで示す。
disabledは薄い灰色の背景、濃い灰色の文字、操作不可のカーソルで示す。
非操作の技術タグにはカーソル・浮き上がり・hover色変更を付けない。
本文と操作部品は1rem、補助情報は0.875rem、見出しはclampで段階的に拡大する。
セクション余白は画面幅に応じて3〜5remで変化する。

## コントラスト計測

sRGBを線形化して相対輝度を求め、`(明るい輝度 + 0.05) / (暗い輝度 + 0.05)`
で計測。通常文字の目標は4.5:1。以下は色トークンの組み合わせの計測であり、
全要素のcomputed styleを取得した自動監査ではない。

| 組み合わせ | コントラスト比 |
| --- | --- |
| 白 / 主要操作の青 #315B8C | 6.99:1 |
| 白 / hoverの青 #24466E | 9.65:1 |
| 濃い青 #24466E / タグ背景 #EDF3FA | 8.64:1 |
| 本文 #243447 / 白 | 12.67:1 |
| 補助文字 #526273 / セクション背景 #F0F4F8 | 5.67:1 |
| 白 / 削除 #B42332 | 6.51:1 |
| 白 / 削除hover #901B28 | 8.85:1 |
| disabled文字 #526273 / 背景 #E2E8F0 | 5.08:1 |
| Hero文字 #ECEFF1 / グラデーションの明るい端 #315B8C | 6.05:1 |
| Hero補助色 #C7DDF5 / 同背景 | 5.02:1 |
