# 作品カード一覧（issue #2）

全作品を順送りなしで閲覧できる一覧に変更した。

- 1100px超は3列、601〜1100pxは2列、600px以下は1列。
- 作品は元データの順に表示し、特定の作品の優先表示や代表作ラベルは付けない。
- `summary` を短い概要として表示。未設定の場合は説明の最初の行を使う。
- 一覧には使用技術を最大3件表示し、残りは詳細内で全件表示する。
- 詳細は標準の `details` / `summary` で展開できる。外部リンクには
  用途別の文言と矢印、新しいタブで開く読み上げ用の案内を付ける。
- 0件は準備中の表示、1件は通常のカードを表示する。
- 画像・説明・タグ・外部リンクが未設定でも表示可能。
- 長文とURLは折り返す。本文はHTMLとして挿入せず、URLだけをリンクにする。

## 検証

`npm run test:projects` で実際のコンポーネントをSSRし、全作品の見出し、
元データの表示順、元データの非破壊、0件・1件、任意項目なし、HTMLの
エスケープ、説明中のURLのリンク化を検証する。ViteのWebSocketは無効にし、
テスト用ポートは開かない。レイアウトやクリック操作を検証するテストではない。

- 本番ビルド成功。
- 上記チェック成功。
- lintはエラーなし（既存AuthContextのFast Refresh警告1件）。
- ChromeでPCの3列表示、長い作品名の折り返し、外部リンクの表記を確認。
- スマホの実表示、詳細のクリック・キーボード操作、カード整列調整後の
  目視確認は未完了。UI操作ツールが `noWindowsAvailable` を返したため。

## 手動確認の残り

390pxと1280pxで作品一覧を開き、カードとタグが横にはみ出さないこと、
詳細がクリックとEnterで開閉できること、フォーカスが見えることを確認する。
特にSIKAPOKEの長い名前と、Listen With 39の本文URLを確認する。
